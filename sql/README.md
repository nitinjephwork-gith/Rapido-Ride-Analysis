# SQL Database

This folder is intended to contain the SQL scripts used in the Rapido Ride Analysis project.

## Database Information

- **Database:** Azure SQL Database
- **Purpose:** Database integration for analytical data and reporting.

## Planned SQL Scripts

This folder can include SQL scripts for:

- Creating database tables
- Loading processed analytical data
- Querying ride-booking information
- Analyzing revenue and booking status
- Generating city-wise and vehicle-wise summaries
